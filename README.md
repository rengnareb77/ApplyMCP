# ApplyMCP
A backend that helps people apply for job by connecting your profile to LLM using MCP protocol.

## Descritpion

Nowadays, when you want to apply for a job, you ask LLM to help you redact your Cover Letter of CV. The goal of this app is to allow LLM to connect to your useful informations (Professionnal experiences, degrees, project, last apply...) MCP protocol. 

These information are stored locally in a database. With the magic of the MCP protocol, you are free to choose the model you want to use to preserve your personal informations.
